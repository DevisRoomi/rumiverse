## 📌 Ringkasan Proyek

**RUMIVERSE** adalah portofolio editorial dan dokumentasi rekayasa sistem terpadu yang menjembatani aplikasi perangkat lunak modern, otomatisasi agen AI mandiri, dan instrumentasi perangkat fisik di lapangan (*Living Lab Lumajang*).

Aplikasi web ini dirancang dengan estetika minimalis editorial (*Swiss architecture / Kinfolk / Stripe Press style*), mengedepankan keterbacaan data yang jujur, tipografi presisi, dan nihil retorika AI generik.

## 🏛 Tiga Sayap Rekayasa (Engineering Wings)

1. **Pilar 01 · Full-Stack Digital Platforms (Web & Mobile)**
   - Perancangan antarmuka modular (*Design System v1.0*).
   - Dasbor pemantauan operasional waktu-nyata (*real-time WebSocket & REST API*).

2. **Pilar 02 · Autonomous AI Workforce**
   - Orkestrasi gugus agen mandiri (*Multi-Agent Swarm Deliberation*).
   - Pipa pemrosesan dokumen dan ekstraksi OCR tanpa prompt monolitik rapuh.
   - Otomasi pengiriman laporan eksekutif 1 halaman PDF & notifikasi ringkas WhatsApp.
   - Konsol telemetri live (*No Black Box*) dengan batas kendali manusia (*Human-in-the-Loop* $\ge 85\%$).

3. **Pilar 03 · Cyber-Physical Systems (Applied IoT & Living Lab)**

   - Kotak instrumen cuaca bersertifikasi **IP66**, pemutus arus MCB, dan modul isolasi optik.
   - Filtrasi ganda hidrolik (pasir silika & karbon aktif) dan manifold dosing otomatis.
   - Jurnal Editorial: `Pillar3JournalModal.tsx`.

## 🗺 Living Lab Lumajang: Smart Integrated Eco-Farm

Fasilitas riset lapangan terpadu di Lumajang dengan prinsip siklus tertutup (*Zero Organic Waste*):
- **Kandang Ayam Smart Coop & Ruminansia** $\rightarrow$ Kotoran organik segar dialirkan langsung.
- **Biokonversi Maggot BSF** $\rightarrow$ Larva bernutrisi tinggi (42% protein kasar) untuk pakan ayam & ikan.
- **Kolam Akuakultur & Rumah Walet** $\rightarrow$ Air kaya nitrat dipompa ke rak hidroponik & mina padi.
- **Hidroponik Bertingkat & Sawah Mina Padi** $\rightarrow$ Pemurnian air kembali ke kolam minum ternak.
- **Mikrogrid Mandiri Energi** $\rightarrow$ Panel surya fotovoltaik, kincir angin mini, dan turbin piko/mikrohidro BioDAS.

## 🚀 Memulai (Local Development)

### Prasyarat
- Node.js (v18+ direkomendasikan)
- npm atau pnpm

### Langkah Menjalankan
1. Pasang dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
3. Buka di peramban web:
   ```
   http://localhost:3000/
   ```

### Verifikasi Tipe Kode
```bash
npm run lint
# atau: npx tsc --noEmit
```
